# Foonix

Use your free-tier LLM keys from one place.

Connect a free key from **Google Gemini**, **NVIDIA**, or **Groq**, then chat in
the browser or call a single OpenAI-compatible API.

- **Bring your own key** — free tiers only, no credit card.
- **Chat + API** — a built-in chat UI and one OpenAI-compatible endpoint.
- **Keys stay yours** — credentials are encrypted at rest.
